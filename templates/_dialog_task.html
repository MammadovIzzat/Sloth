nmap's most common ports, by frequency. 1000 is nmap's own default.

Slower than masscan but nmap retransmits, so it doesn't lose ports to packet loss. Use 1-65535 when a masscan sweep looks thin.

masscan's own default is 0 retries — one SYN per port, never retransmitted, so a single dropped probe loses that port silently.
